# 七步安装向导

## 目标

让没有任务应用、不了解插件和不愿打开终端的用户，在十分钟内看到第一份真实预览。Agent 负责运行命令，用户只做选择和输入任务。

## 七步

1. 语言：中文默认，可选英文。
2. 环境体检：显示操作系统、宿主、本地数据库、已发现能力；不把“检测不到”说成“不支持”。
3. 作息：设置时区、通常清醒时间、工作时间和午休。
4. 来源：逐项说明能读什么、不能读什么、是否只读、数据保存多久。此时不主动登录或授权。
5. 任务入口：默认创建本地收集箱；已有外部任务应用时仍以原应用为真源。
6. 真实预览：输入 3–10 个真实任务，生成首份简报，逐项解释排序与延期原因。
7. 每日运行：预览通过后才询问是否使用宿主调度。说明运行时间、通知方式、停用入口和来源失败的降级行为。

## 平台分支

- iPhone + Mac：优先复用 Mac 上宿主已获授权的日历/提醒事项能力。
- iPhone 无 Mac：明确 Apple 私有数据无法保证自动读取；提供 Google/Microsoft、ICS 或本地收集箱。
- Android：优先宿主已有 Google/Microsoft 能力；否则使用标准文件或人工输入。
- 无邮件插件：显示“未连接”，允许粘贴行动摘要或跳过，不自建 IMAP/OAuth。
- 无调度能力：保留立即生成和自然语言触发，不安装系统计划任务。

## 完成检查

- 用户看到了真实任务生成的预览，不是演示数据。
- 可选来源失败没有阻断简报，也没有显示为零。
- 用户知道外部来源只读，本地任务才可编辑。
- 只有用户明确同意，才创建宿主定时任务。
