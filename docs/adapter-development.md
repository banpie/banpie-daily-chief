# 适配器开发指南

## 职责

适配器只做三件事：声明能力、读取当前宿主数据、转换成 `SourceSnapshot`。不要复制优先级、容量、去重、排程或校验规则。

## 必填声明

- `adapter_id` 与 `api_version`
- 能力列表
- 宿主、操作系统和数据提供方
- 可用性、登录需求、只读状态
- 最近成功读取时间
- 失败原因和人工恢复入口

## 输出要求

使用 `packages/core/schemas/v1/SourceSnapshot.schema.json`。失败时 `items` 必须为空，状态必须是 `not_connected`、`login_required`、`read_failed`、`stale` 或 `not_read`。只有 `ok` 可提供本轮事项。

邮件适配器默认只输出主题、发件人、日期、线程入口和行动摘要，不保存正文。任务和日历适配器必须保留原入口与原应用真源。所有公共适配器默认只读。

## 测试

适配器至少覆盖：成功、未连接、登录过期、超时、旧缓存、全天/跨日事件、时区、重复入口和已完成任务。使用合成数据；不得提交真实账号或个人路径。
