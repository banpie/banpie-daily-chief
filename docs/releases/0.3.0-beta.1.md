# 半撇每日参谋 0.3.0 预览版

这是首个可供真实试用的公开预览版，尚不是 1.0。

## 已包含

- 版本化 JSON Schema、去重、容量排程、最多五项行动和确定性校验。
- SQLite 本地收集箱、任务、项目、运行记录和数据保留机制。
- 七步中文默认 onboarding、英文简报输出和响应式本地网页。
- 通用 Skill、WorkBuddy 插件包、Codex 插件包和固定版本源码安装器。
- ICS、CSV、Markdown、JSON 导入，以及没有插件时的完整降级运行。
- Apache 2.0、隐私说明、安全政策、贡献指南和适配器开发文档。

## 已验证

- 17 项公共自动测试通过。
- Chrome 桌面和 390px 手机宽度完成七步首次使用走查，控制台零错误。
- 三个发布压缩包通过 SHA-256 和 ZIP 完整性检查。
- 半撇私人扩展继续通过 Ruby 46 项 / 445 个断言和 Python 22 项回归。

## 仍待公测

- 新 macOS、新 Windows 的十分钟无终端安装验收。
- WorkBuddy 与 Codex 各一次真实自然语言运行和一次定时运行。
- npm 首次发布需要维护者完成注册表登录；当前安装器固定使用本 GitHub 标签。
