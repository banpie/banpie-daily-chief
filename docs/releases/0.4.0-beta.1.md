# 半撇每日参谋 0.4.0 预览版

## 本版完成

- 七步向导改用真实 `CapabilityReport`，支持刷新恢复、返回修改和幂等首份预览。
- 没有任务系统的用户可创建 3–10 项真实任务并在向导内接受首份计划。
- 任务、项目、重复系列与版本化日计划可以完整维护；时间冲突、过去时间和缓冲缩减会被拦截。
- 中文与英文覆盖向导和主要工作台页面，网页与聊天共用同一份简报数据。
- Codex 和 WorkBuddy 市场清单通过宿主校验，Codex 插件包含界面元数据、图标、新手提示和真实截图。
- macOS arm64/x64、Windows x64 改用带 Node 的预构建运行时；安装时校验 SHA-256，切换失败保留旧版本和用户数据库。
- Playwright 覆盖新人闭环、刷新恢复、任务/项目编辑、冲突拦截、手机宽度和英文界面。

## 仍需真实验收

- 全新 macOS 与 Windows 的十分钟无终端安装计时。
- Codex 与 WorkBuddy 各一次新任务自然语言运行和一次宿主原生定时运行。
- 私人半撇版本锁定公共内核后的完整回归与一次真实日运行。

这些门槛通过前不会发布 `1.0.0`。
